# 🏋️‍♂️ GT Treinos

> Sua ficha de academia digital, minimalista e eficiente.

## 💻 Sobre o Projeto

O **GT Treinos** é uma aplicação web desenvolvida para substituir as fichas de papel e os blocos de notas do celular na hora do treino.

O objetivo principal deste projeto foi consolidar conhecimentos em **JavaScript Puro (Vanilla)**, manipulação de DOM e lógica de programação sem o uso de frameworks (como React ou Vue), focando na performance e no entendimento da base da web.

## ⚙️ Funcionalidades

- [x] **Criação de Treinos:** Monte fichas personalizadas (Treino A, B, C...).
- [x] **Banco de Exercícios:** Adicione exercícios com nome, séries, repetições e carga.
- [x] **Persistência de Dados:** Seus treinos ficam salvos no navegador (LocalStorage) e não somem ao atualizar.
- [ ] **Modo Execução:** Checklist para marcar exercícios concluídos em tempo real. *(Em breve)*
- [ ] **Timer de Descanso:** Cronômetro integrado para pausas entre séries. *(Em breve)*

## 🛠 Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias principais:

- **HTML5** (Semântico)
- **CSS3** (Flexbox, Grid e Variáveis CSS)
- **JavaScript (ES6+)**
